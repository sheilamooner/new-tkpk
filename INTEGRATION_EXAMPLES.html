📚 Usage in Your Pages

Step 1: Include the Script

<script src="/assets/telegram-integration.js"></script>

Step 2: Use the API

Auto-tracking (automatic):

// Automatically tracks visitor on first interaction
// No code needed!

Form handling:

const form = document.getElementById('myForm');
window.TelegramIntegration.handleForm(
    form,
    (result) => console.log('Success!', result),
    (error) => console.error('Error!', error)
);

Custom events:

await window.TelegramIntegration.send({
    action: 'custom_event',
    data: 'your data here'
});

Manual tracking:

await window.TelegramIntegration.track();
🔒 Security Note: The integration automatically detects and ignores bot traffic. Real user interactions are tracked while crawlers see clean, static content.
